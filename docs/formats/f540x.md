# `.f540x` — Fusion 360 interchange bundle

Written by the Fusion bridge add-in (`tools/fusion-bridge/`) from inside Fusion 360, read by Fission540. The same schema will be used in the other direction (Fission540 → Fusion).

Status: **schema 0 (draft)**. Fields may change until the Fission540 importer exists; readers must check `schema`.

## Container

A zip file:

| path | content |
|---|---|
| `design.json` | parametric description (below) |
| `step/assembly.step` | root component with all occurrences (STEP AP214, from Fusion's exporter) |
| `step/<component id>.step` | each component that has bodies, in its own coordinates |
| `source.f3d` | Fusion archive of the design, for later re-import and `.f3d` format research |
| `export.log` | warnings from the export (entities that could not be described) |

## Conventions

- **Units:** Fusion's internal units, unchanged: lengths in **cm**, angles in **radians**, areas cm², volumes cm³. `units.display` records the design's display unit for parameters.
- **Points/vectors:** `[x, y, z]`. **Matrices:** 16 numbers, row-major 4×4 as returned by Fusion's `Matrix3D.asArray()`; translation in elements 3, 7, 11.
- **Parameters:** `{"name", "expression", "value", "unit"}`; `value` is in internal units. Feature inputs refer to parameters by name.
- **Ids:** strings assigned by the exporter, unique within the file: `c<n>` components, `o<n>` occurrences, `s<n>` sketches, `<sketch id>.<n>` sketch entities, `j<n>` joints. Fusion `entityToken`s are stored as `token` where available but are only meaningful inside the original Fusion document.
- **Enums** are exported as Fusion's API names (`objectType` without the `adsk::fusion::` prefix; enum values as names where the add-in knows them, otherwise the integer).
- Anything the exporter cannot describe is still listed with its `type` and `name`, plus `"unsupported": true`, so the importer can flag it in the timeline.

## `design.json`

```jsonc
{
  "schema": "f540x/0",
  "source": { "name": "...", "fusionVersion": "...", "dataFileId": "...", "version": 12, "exported": "2026-11-25T10:00:00Z" },
  "units": { "length": "cm", "angle": "rad", "display": "mm" },
  "designType": "parametric",            // or "direct" (no timeline)
  "userParameters": [ { "name": "width", "expression": "40 mm", "value": 4.0, "unit": "mm", "comment": "" } ],
  "modelParameters": [ { "name": "d1", "expression": "width / 2", "value": 2.0, "unit": "mm", "role": "AlongDistance", "createdBy": "Extrude1" } ],
  "components": [ ... ],
  "rootComponent": "c0",
  "occurrences": [ ... ],                 // tree, root's children first
  "sketches": [ ... ],
  "timeline": { "markerPosition": 7, "items": [ ... ] },
  "joints": [ ... ]
}
```

### Component
`{ "id", "name", "partNumber", "description", "material", "token", "bodies": [Body], "constructionPlanes": [...], "constructionAxes": [...], "constructionPoints": [...] }`

Body: `{ "name", "solid", "visible", "material", "appearance", "volume", "area", "faces", "edges", "step": "step/c1.step" }` (volume/area from Fusion's physical properties, used to check the import).

### Occurrence
`{ "id", "name", "path", "component", "transform": [16], "grounded", "visible", "children": [Occurrence] }`. `transform` is relative to the parent component.

### Sketch
```jsonc
{ "id": "s0", "name": "Sketch1", "component": "c0",
  "plane": Ref,                       // construction plane or B-rep face it was created on
  "transform": [16],                  // sketch space -> component space
  "points":      [ { "id": "s0.0", "position": [x, y, z], "fixed": false, "reference": false } ],
  "curves":      [ { "id": "s0.4", "type": "SketchLine", "start": "s0.0", "end": "s0.1", "construction": false, ... } ],
  "constraints": [ { "type": "HorizontalConstraint", "entities": { "line": "s0.4" } } ],
  "dimensions":  [ { "type": "SketchLinearDimension", "entities": { "entityOne": "s0.0", "entityTwo": "s0.1" }, "parameter": "d1", "driving": true, "orientation": "Horizontal" } ],
  "profiles":    [ { "loops": [ { "outer": true, "curves": ["s0.4", "s0.5", ...] } ] } ] }
```
Point positions are in sketch space. Curve types and their fields:

| type | fields |
|---|---|
| `SketchLine` | `start`, `end` (point ids) |
| `SketchCircle` | `center`, `radius` |
| `SketchArc` | `center`, `start`, `end`, `radius`, `startAngle`, `endAngle`, `normal`, `referenceVector` |
| `SketchEllipse` | `center`, `majorAxis` (vector), `majorRadius`, `minorRadius` |
| `SketchEllipticalArc` | as ellipse + `start`, `end`, `startAngle`, `endAngle` |
| `SketchFittedSpline` | `fitPoints` (point ids), `closed`, `nurbs` |
| `SketchFixedSpline` | `nurbs` |
| `SketchConicCurve` | `start`, `end`, `apex`, `rho` |

`nurbs`: `{ "degree", "controlPoints": [[x,y,z]], "knots", "weights" (null if non-rational), "periodic" }`.
All curves carry `construction`, `fixed`, `reference` (projected/included geometry), `fullyConstrained`.
Constraint and dimension `entities` keep Fusion's API property names (`lineOne`, `curveTwo`, `point`, `symmetryLine`, ...).

### Ref (reference to model geometry)
B-rep references are stored as geometric signatures, since Fusion's entity tokens do not survive outside the document:

| kind | fields |
|---|---|
| `face` | `body`, `component`, `surface` (type), `point` (on face), `centroid`, `area`, `normal` (at `point`) |
| `edge` | `body`, `component`, `curve` (type), `start`, `end`, `point` (on edge), `length` |
| `vertex` | `body`, `component`, `point` |
| `body` | `body`, `component` |
| `sketchEntity` | `sketch`, `entity` |
| `profile` | `sketch`, `loops` (as in the sketch's `profiles`) |
| `constructionPlane` / `constructionAxis` / `constructionPoint` | `name`, `component` (origin planes are `XY`, `XZ`, `YZ`; axes `X`, `Y`, `Z`; point `Origin`) |
| `occurrence` | `occurrence` id |
| `parameter` | `name` |

Signatures are taken at the timeline marker state of the export, not at the feature's own position in the timeline. The importer matches them against its own geometry at the feature's position; a mismatch is a timeline error, never a silent rebinding.

### Timeline item
`{ "index", "name", "suppressed", "rolledBack", "group": "Group name" | null, "entity": Entity }`

Entity is one of:
- `{ "kind": "sketch", "sketch": "s3" }`
- `{ "kind": "occurrence", "occurrence": "o2" }` (new component)
- `{ "kind": "joint", "joint": "j0" }`
- `{ "kind": "feature", "type": "ExtrudeFeature", "name", "component", "health", "message", "parameters": ["d4", "d5"], "bodies": ["Body1"], ...type-specific fields }`

Type-specific feature fields in schema 0:

| type | fields |
|---|---|
| `ExtrudeFeature` | `profile` (Ref or list), `operation`, `start` (Extent), `extentOne`, `extentTwo` (Extent or null), `taperOne`, `taperTwo` (parameter names), `participantBodies` |
| `RevolveFeature` | `profile`, `axis` (Ref), `operation`, `extentOne`, `extentTwo` |
| `FilletFeature` | `edgeSets`: `[ { "type", "edges": [Ref], "radius": param, "tangentChain" } ]` |
| `ChamferFeature` | `edgeSets`: `[ { "type", "edges": [Ref], "distance", "distanceOne", "distanceTwo", "angle" (param names), "tangentChain" } ]` |
| `ShellFeature` | `inputEntities` [Ref], `inside`, `outside` (param names), `tangentChain` |
| `HoleFeature` | `holeType`, `position`, `direction`, parameters by role |
| `CombineFeature` | `target` (Ref), `tools` [Ref], `operation`, `keepTools` |
| `MirrorFeature` | `inputEntities` [Ref], `mirrorPlane` (Ref) |
| `RectangularPatternFeature` / `CircularPatternFeature` | `inputEntities` [Ref], `directionOne`/`directionTwo` or `axis` (Ref), quantity/distance/angle param names |
| `ConstructionPlane` / `ConstructionAxis` / `ConstructionPoint` | `definition` (type) + its input Refs and parameters |
| anything else | generic fields only (`unsupported: true`) |

Extent: `{ "type": "DistanceExtentDefinition", "distance": "d4" }`, `{ "type": "SymmetricExtentDefinition", "distance", "fullLength" }`, `{ "type": "ToEntityExtentDefinition", "entity": Ref, "offset", "chained" }`, `{ "type": "ThroughAllExtentDefinition", "positive" }`, `{ "type": "AngleExtentDefinition", "angle", "symmetric" }`, `{ "type": "FullExtentDefinition" }`, start: `ProfilePlaneStartDefinition`, `OffsetStartDefinition` (`offset`), `EntityStartDefinition` (`entity`, `offset`).

### Joint
`{ "id", "name", "kind": "joint" | "asBuilt", "motion": "RevoluteJointMotion", "occurrenceOne", "occurrenceTwo", "geometryOne", "geometryTwo", "offset", "angle", "flipped", "suppressed", "limits": {...}, "values": {...} }`
Joint geometry: `{ "origin", "primaryAxis", "secondaryAxis", "thirdAxis", "type", "keyPointType", "entityOne": Ref }`.
